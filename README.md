# FSP IT Talent Match

Цифровая платформа-агрегатор ИТ-вакансий с верифицированным профилем
достижений участника Федерации спортивного программирования.

Прототип разработан в рамках хакатона «Лидеры цифровой трансформации 2026».

## О задаче

Существующие площадки поиска работы универсальны и не решают задачу
релевантного подбора в ИТ. Работодатель тонет в нерелевантных откликах,
кандидат откликается вслепую и не получает обратной связи.

Платформа меняет механику: **инициатива исходит от работодателя**.
Кандидат проходит обязательное тестирование, получает категорию
«специализация + грейд» и становится виден в ранжированной выдаче.
Работодатель описывает потребность, получает объяснимую подборку и
отправляет адресное приглашение с указанием зарплаты. Контакты
раскрываются только после принятия приглашения.

## Ключевые особенности

- **Два ролевых кабинета:** кандидат и работодатель.
- **Обязательное тестирование:** опрос, выбор грейда, тест.
- **Автоматическая категоризация:** специализация + подтверждённый грейд.
- **Антиутечка заданий:** параметризованные шаблоны вопросов, случайная
  выборка и порядок вариантов.
- **Взвешенный подсчёт** с разделяющей силой: сложные вопросы весят больше.
- **Объяснимый подбор:** работодатель видит, почему кандидат в топе.
- **Адресное приглашение:** без обязательной привязки к вакансии, с
  зарплатой и описанием предложения.
- **Правила видимости:** контакты открываются только после принятия.
- **Интеграция с ФСП ID:** имитация привязки, мок-сервис достижений и
  скелет будущей интеграции с Keycloak.
- **Обработка кандидата без истории ФСП.**

## Технологии

- **Backend:** FastAPI, SQLAlchemy 2.0, Alembic, PostgreSQL, Pydantic v2.
- **Frontend:** Jinja2, HTMX, ванильный CSS.
- **Auth:** JWT в httpOnly cookie, bcrypt.
- **Инфраструктура:** Docker Compose (app, db, mini-fsp-id, mailpit).
- **Тесты:** pytest, pytest-playwright.

## Быстрый старт

Нужен только Docker с Compose v2.

```bash
cp .env.example .env
docker compose up --build
```

После запуска:

- Приложение: http://localhost:8000
- Swagger: http://localhost:8000/docs
- Мок FSP ID: http://localhost:8001/docs
- Mailpit (почта): http://localhost:8025

## Сквозной сценарий

1. Кандидат регистрируется, подтверждает email, проходит тест на грейд.
2. Система присваивает категорию: специализация + подтверждённый грейд.
3. Работодатель ищет кандидатов по фильтрам, видит рейтинг и причины.
4. Работодатель отправляет адресное приглашение с зарплатой.
5. Кандидат принимает или отклоняет.
6. При принятии контакты кандидата раскрываются работодателю.

## Тесты

Unit (без внешних сервисов):

```bash
uv run --locked pytest tests/backend -q
```

Integration (требует запущенного Compose):

```bash
docker compose exec -e RUN_INTEGRATION=1 \
  -e APP_BASE_URL=http://localhost:8000 \
  -e FSP_BASE_URL=http://mini-fsp-id:8000 \
  -e MAILPIT_BASE_URL=http://mailpit:8025 \
  app uv run --locked --group dev pytest tests/integration -q
```

E2E (Playwright):

```bash
uv run playwright install chromium
RUN_E2E=1 APP_BASE_URL=http://localhost:8000 \
  uv run --locked pytest tests/e2e -q
```
